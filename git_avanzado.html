CONCEPTO FUNDAMENTAL

¿Qué es Git?

📦

Control de versiones

Git permite registrar los cambios realizados en un proyecto a lo largo del tiempo.

🕐

Historial

Cada commit representa un punto de control al que podemos volver o consultar.

👥

Trabajo en equipo

Permite que varias personas trabajen sobre el mismo proyecto y compartan cambios.

💡 Idea clave

Git no es GitHub. Git es el sistema de control de versiones. GitHub es una plataforma donde podemos alojar repositorios Git.

PRIMEROS PASOS

Configuración inicial de Git

1

Verificar instalación 

git --version

Permite comprobar que Git está instalado y conocer la versión disponible.

2

Configurar nombre 

git config --global user.name "Tu Nombre"

Guarda el nombre que Git asociará a tus commits.

3

Configurar correo 

git config --global user.email "correo@example.com"

Configura la dirección de correo asociada a tus commits.

4

Ver configuración 

git config --global --list

Muestra las configuraciones globales de Git.

05

GUARDAR CAMBIOS

Add + Commit

git add . → git commit -m "cambio"

Primero seleccionamos los cambios y luego creamos un punto de control.

🔎 Analicemos: 

git commit -m "cambio"
  • git → ejecuta Git.
  • commit → crea un registro de los cambios.
  • -m → permite escribir un mensaje.
  • "cambio" → descripción del commit.
💡 Buena práctica

Los mensajes de commit deberían explicar qué cambio se realizó.

git commit -m "Agrega formulario de login" git commit -m "Corrige estilos del menú" git commit -m "Agrega validación del formulario"

BRANCHES

Trabajar con ramas

Las ramas permiten trabajar sobre distintas líneas de desarrollo sin modificar directamente la rama principal.

main
feature-login
git branch

Ver ramas

Lista las ramas existentes.

git branch nueva-rama

Crear rama

Crea una nueva rama.

git switch nueva-rama

Cambiar de rama

Cambia a otra rama.

git switch -c login

Crear y cambiar

Crea una rama y cambia inmediatamente a ella.

08

INTEGRACIÓN

Merge

merge permite integrar los cambios de una rama dentro de otra. 

git switch main
git merge login
⚠ Posible conflicto

Si dos ramas modificaron las mismas líneas, Git puede solicitar que resolvamos manualmente el conflicto.

09

REPOSITORIOS REMOTOS

Git + GitHub

💻 PC Repositorio local
↕
☁️ GitHub Repositorio remoto

Agregar repositorio remoto 

git remote add origin URL_DEL_REPOSITORIO

Ver repositorios remotos 

git remote -v

Subir cambios 

git push -u origin main
  • push → envía cambios al repositorio remoto.
  • -u → establece la rama remota de seguimiento.
  • origin → nombre habitual del repositorio remoto.
  • main → rama que estamos enviando.

Descargar cambios 

git pull origin main

Clonar un repositorio 

git clone URL_DEL_REPOSITORIO

BUENAS PRÁCTICAS

El archivo .gitignore

.gitignore permite indicar qué archivos o carpetas Git debe ignorar. 

# Dependencias
node_modules/

# Variables de entorno
.env

# Archivos temporales
*.tmp

# Sistema operativo
.DS_Store

# Logs
*.log
🔐 Importante

Nunca deberíamos subir contraseñas, tokens, claves privadas o archivos con información sensible al repositorio.

RECUPERACIÓN

Deshacer cambios

Comando
¿Para qué sirve?
git restore archivo
Descarta cambios no confirmados de un archivo.
git restore --staged archivo
Quita un archivo del staging.
git revert ID
Crea un nuevo commit que revierte otro commit.
git reset --hard
Puede eliminar cambios locales. Usar con mucha precaución.
⚠ Atención

Los comandos como git reset --hard pueden provocar pérdida de cambios. No deben utilizarse sin entender primero qué información estamos eliminando.

PROBLEMAS FRECUENTES

Errores habituales

¿Qué hago si dice "not a git repository"?

Probablemente estás en una carpeta que todavía no fue inicializada como repositorio. 

git init
¿Qué significa "nothing to commit"?

Significa que Git no detecta cambios nuevos para guardar.

¿Por qué aparece "rejected" al hacer push?

Puede ocurrir porque el repositorio remoto contiene cambios que todavía no tenemos localmente. 

git pull origin main
¿Cuál es la diferencia entre Git y GitHub?

Git es el sistema de control de versiones. GitHub es una plataforma que permite alojar repositorios Git y trabajar colaborativamente.
